# 未纳入及部分覆盖的已知情况

以下说明包含未纳入的应用，以及已纳入应用中未覆盖的入口。这些限制不属于安装后替换失败；未替换列表不显示这些原因。

| 应用 | 当前情况 |
|---|---|
| QQ | 有正常的经典企鹅素材，红围巾不属于额外装饰；当时原图资源未解析完成，尚未适配 |
| 抖音 | 图标资源名被混淆，暂未可靠适配 |
| 闲鱼 | 0.3.6 改为通过数值 ID 处理普通入口，已通过隔离验证。活动、会员等备用入口不在当前目标内；没有确认应用当前是否开放自选图标界面 |
| 岚图汽车 | 用户确认现有图标裁切可接受，选择保留原图 |

拼多多 0.3.4/0.3.5 只覆盖了声明别名，实际桌面使用已解析的另一资源，因此没有效果。0.3.6 改为数值 ID 映射并补齐真实目标的自适应配置，已通过隔离验证；不能把旧版的资源检查通过当作实际生效。

招商银行、高德地图已在 0.3.9 纳入，分别处理 13.2.0 / 1320、17.02.2.2014 / 170105 中的拆分包桌面图标。使用补全计划默认前后景素材；初始映射保留原资源，校准后覆盖实际桌面 ID。构建与隔离验证进展见 [验证记录](validation.md)，尚未安装新模块。

其它未纳入的应用可能已经规范，也可能尚未评估；没有逐个确认的条目不推断原因。这些应用在界面中只标“未替换”。0.3.8 起不再展示“仅普通入口”标签，当前入口未适配时应如实显示未生效；后续发现遗漏再补对应资源，不切换应用的启动组件。

本模块已纳入但实际未生效的应用，才在界面显示“说明”，内容来自资源检查结果，包括覆盖未启用、映射缺失或系统仍选用原图标。无法完成状态查询时显示“未确认”，不冒充替换失败。
